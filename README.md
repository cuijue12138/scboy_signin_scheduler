#scboy_登录调度程序  
scboy_signin_scheduler自动签到工具
项目简介
scboy_signin_scheduler自动签到工具是一款基于Python的自动化脚本，用于scboy论坛的每日自动签到。该工具支持定时任务执行，并提供钉钉和邮件通知功能。

功能特性
自动签到：自动完成scboy论坛的每日签到任务
定时执行: 支持北京时间每天早上 9 点自动执行
钉钉通知: 签到结果实时推送到钉钉群
邮件通知: 支持邮件方式发送签到报告
日志记录: 详细的日志记录，便于问题排查
安装依赖
pip 安装 requests pytz apscheduler
配置说明


1. 配置文件设置
编辑 config/config.ini 文件，填入相应的配置信息：
; ======================
; SCBOY 账号配置
; 每个账号以 [SCBOY_数字] 命名
; ======================

[SCBOY_1]
电话 =
密码 =


[dingding] (可选)
Webhook = 钉钉机器人 Webhook URL

; ======================
; 邮箱通知配置（以 QQ 邮箱为例）
; ======================

[电子邮件]
SMTP服务器 = smtp.qq.com
SMTP端口 = 587
发件人 = your_email@qq.com
密码 = your_SMTP授权码
收件人 = your_email@qq.com, friend@example.com

使用方法
脚本默认运行在定时任务模式，脚本第一次执行时候，会执行签到，后面是会在每天北京时间早上 9 点自动执行签到任务。启动后会持续运行，等待预定时间执行。

nohup python3 scboy_signin_scheduler.py &
启动成功提示信息
任务已设定，将在每天北京时间 09:00 执行。当前时间：
2026-01-31 12:10:00
📬 通知功能
脚本执行完成后会自动发送通知，包含以下信息：
登录状态
签到结果
积分查询结果（如支持）
执行时间
通知方式：
钉钉通知：发送到配置的钉钉群（可选）
邮件通知：发送到配置的邮箱（可选）
📁 日志说明
日志文件保存在 logs/ 目录下
按日期自动分割，格式为 YYYY-MM-DD.log
包含详细的执行过程和错误信息，便于排查问题
⚠️ 注意事项
配置文件安全：请妥善保管 config/config.ini，避免泄露账号密码等敏感信息
邮箱设置：使用 163、QQ 等邮箱时，需在邮箱后台开启 SMTP 服务，并使用 授权码（非登录密码）
持续运行：定时任务模式需要保持脚本持续运行（建议部署在服务器或常开电脑）
🛠️ 故障排除
登录失败：检查手机号与密码是否正确，确认未被封号
通知发送失败：检查钉钉机器人 Webhook 地址或邮箱 SMTP 配置是否正确
定时任务不执行：确保脚本未意外退出，系统时间与时区（Asia/Shanghai）设置正确
💡 提示：首次运行会立即执行一次签到，后续每天 09:00 自动执行。
